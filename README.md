# PowerBI_Project
Netflix Content &amp; Engagement Analytics Dashboard

# Executive Summary
This Power BI project provides an interactive and data-driven analysis of Netflix's content library, focusing on movie and TV show performance, viewer engagement (IMDb ratings and votes), runtime patterns, and age content ratings. The goal of this dashboard is to deliver actionable insights into content trends and viewer reception over time.

# Key Features & Visualizations
- **1. Core Performance & Engagement MetricsTop Movies & TV Shows:** Bar chart displaying top-performing titles based on total engagement metrics.   IMDb Rating Trends: Tracking the average IMDb score across release years to monitor quality perception over time.   Voting Volume Trends: Line chart showing user interaction and voting volume by release year.   
-- **2. Content Distribution & Demographic AnalysisContent Type Breakdown:** Interactive toggle for filtering data between Movies and TV Shows.   Age Certification Distribution: Visual breakdown analyzing title counts across age ratings (e.g., PG-13, TV-MA, R).   Yearly Content Distribution: Donut charts illustrating annual volume shifts for both movies and TV shows.   
- **3. Advanced Metrics & Interactive FilteringRuntime vs. Audience Engagement:** Analysis examining the relationship between media runtime and IMDb ratings/votes.   Dynamic Slicers: Interactive controls allowing users to slice data by release year range, media runtime, and content category.
